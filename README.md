# ききがき手帳

村の人や古い書物から「手がかり」を1つずつ聞いて、妖怪と神話の神さまの正体を当てる1日5問のゲーム。前もって知らなくても、遊ぶうちに妖怪・日本の神話・世界の神話を覚えられます。時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/kikigaki-techo/
- 今日の5問（妖怪・日本の神話・世界の神話を1つずつ＋ふつう1・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・手がかり2つだけ）、練習（何度でも・まだ当てていない正体から）、とことん（全103の正体を次々に）があります。
- 手がかりは3つまで。少ない手がかりで当てるほど★が多くなります。まちがえても選び直せます。
- 当てた正体は「ききがき帳」に書きとめられ、手がかり・説明・出典を読み返せます。
- 見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）と、記録を別の端末へ移す「引き継ぎ」があります。

## 話のもと（出典）

正体ごとの出典は `data.js` の `src` と、ゲームの中（当てたあと・ききがき帳）に書いてあります。

- 妖怪：鳥山石燕『画図百鬼夜行』、柳田國男『遠野物語』『妖怪談義』、小泉八雲『怪談』、『平家物語』、御伽草子、各地の伝承など
- 日本の神話：『古事記』（一部『日本書紀』）
- 世界の神話：ヘシオドス『神統記』、オウィディウス『変身物語』、『エッダ』、『ギルガメシュ叙事詩』、『淮南子』など

伝承や神話は土地や書物によって話がちがうことがあり、ここではよく知られている形をとりました。まちがいに気づいたら、感想のフォームで教えてください。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（正体の名前は入りません）。

## 開発

```bash
bash scripts/setup.sh   # 最初に一度
node qa/run.mjs         # 検査（CI と同じ）
```

問題のもとは `data.js`（決まりは AGENTS.md）。
